# React useEffect Timer

A very simple timer made with React, `useState`, `useEffect`, and CSS.

## Run in VS Code

1. Extract this ZIP file.
2. Open the extracted `focus-stopwatch-basic` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local address shown in the terminal.

The timer starts automatically. Use **Stop Timer** to pause, **Start Timer** to continue, and **Reset Timer** to reset it to zero.
